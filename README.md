# KnownAsNeo Portfolio
Responsive, single-page portfolio website using HTML, CSS, and JavaScript.

## Run
Open `index.html` in your browser. No build tools required.

## Customize before publishing
- In `script.js`, replace `YOUR_EMAIL@example.com` with your contact email.
- In `index.html`, replace the placeholder Discord username and GitHub URL with your real public links.
- Review project descriptions and keep only claims that accurately represent your work.
- Deploy the folder to Netlify or GitHub Pages.

The contact form opens the visitor's email app; it does not store submissions.
